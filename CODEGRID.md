# RollHelper Code Grid

Этот файл оставлен в корне специально для поиска по словам `code grid` / `кодгрид`.

Главная актуальная карта кода: `docs/CODEMAP.md`.

Порядок для нового агента:

1. `docs/CODEMAP.md` — фактические entrypoint, зависимости, данные и релизы.
2. `STATUS.md` — текущее состояние и известные проблемы.
3. Документ нужной подсистемы.
4. `PLAN.md`, `PROJECT_BACKLOG.md` и архитектурную декомпозицию использовать только как историю и целевой план.

Не начинать работу с бэкапов `*.BEFORE_*`, старых portable-сборок или `RollHouseLite*`.
