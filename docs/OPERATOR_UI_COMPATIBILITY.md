# Совместимость интерфейса для оператора

Этот документ обязателен для каждого нового бренда, модуля и окна настроек. Его цель — не повторять уже найденные ошибки с кодировкой, масштабом Windows и тесной версткой.

## Базовые правила

1. Все AHK v1-файлы, которые попадают в ZIP-пакет, сохраняются в UTF-8 с BOM. Это относится и к подключаемым `.ahk`-файлам. Без BOM кириллица в AHK v1 может превратиться в нечитаемые символы.
2. Текст операторского интерфейса хранится в исходниках в нормальной украинской или русской кириллице. Нельзя использовать байтовые «исправления», HTML-сущности или ручную перекодировку строк.
3. Основной шрифт: `Segoe UI`. Нельзя полагаться на emoji-шрифт для смысла кнопки или статуса.
4. У каждой видимой кнопки есть короткая текстовая подпись. Иконка может дополнять подпись, но не заменять её.

## Масштаб Windows и экраны

Перед выпуском нового окна проверять его на масштабе Windows 100%, 125% и 150%.

- Окно должно помещаться на экране ноутбука 1366×768 при 125% без ухода основных кнопок за нижнюю или правую границу.
- Нельзя привязывать критичные действия к фиксированным координатам окна.
- Нельзя рассчитывать ширину кнопок только под один размер текста: украинские слова часто длиннее.
- Для групп кнопок использовать единый размер, перенос текста или `WrapPanel`; кнопки не должны налезать друг на друга.
- Для длинных полей использовать растягивание по ширине и обрезание второстепенного текста, а не выход за границу.
- Таблицы должны позволять менять ширину колонок. Сохранённая разметка не должна сбрасываться при обновлении списка или самого лаунчера.

## Лаунчер: понятная модель обновлений

Оператор видит три разных уровня, и они не смешиваются:

- Лаунчер — обновляется отдельной кнопкой в шапке.
- Программа бренда — обновляется только когда изменился её ZIP-пакет.
- Дополнение — обновляется в правой панели дополнений выбранного бренда.

Если изменилось только дополнение, строка бренда не должна получать статус «Доступно обновление». У дополнения должна быть кнопка `Обновить`, а не `Установить`.

Правое окно дополнений закрыто, пока оператор не выберет бренд. Его можно закрыть кнопкой, `Esc` или кликом по пустому месту списка программ.

## Проверка перед релизом

1. Открыть пакет на 100%, 125% и 150% масштабе Windows.
2. Проверить кириллицу в пульте, настройках, сообщениях, трее и отдельном модуле.
3. Проверить, что элементы не выходят за границы и не перекрывают друг друга.
4. Проверить сценарий без установленного дополнения, с установленным дополнением и с доступным обновлением дополнения.
5. Проверить, что обновление только дополнения не предлагает обновить бренд.
6. Проверить, что обновление лаунчера не меняет установленные пакеты, пользовательские настройки и разметку окна.
