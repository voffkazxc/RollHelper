# RollHelper — единый пульт (Roll House ⇄ Roll Club)

> **СТАТУС 2026-07-15 (историческая заметка):** этот план частично не реализован.
> Общий `engine/` (модульный #Include) НЕ выделен — папка `engine/` пустая. По факту:
> Roll House = монолитный `main.ahk`, Roll Club = монолитный `engine_rollclub.ahk` (~3700 строк),
> `main.ahk` запускает `engine_rollclub.ahk` при `Brand=rollclub`. Так что «один движок» —
> это лаунчер + два отдельных монолита, а не общий модульный движок.
> Актуальное поведение RC: `АВТО_КЦ_ПРОТОКОЛ.md`, `STATUS.md`, `HANDOFF.md`.

Цель: один движок, переключатель брендов вместо двух отдельных скриптов.
Чинишь баг один раз — работает в обоих. Переключаешь бренд птичкой в окне.

## Структура

```
RollHelper/
  main.ahk                 ← точка входа: выбор бренда + подключение движка
  engine/                  ← ОБЩИЙ код (один на оба бренда)
    config.ahk   parser.ahk   ui.ahk   iiko.ahk   siv.ahk   payment.ahk
  brands/
    rollhouse/             ← данные Roll House
      RkConfig.ini  RkTemplates.txt  DeliveryPrices.ini  *.kml  img/
    rollclub/              ← данные Roll Club
      RkConfig.ini  RkPromo.ini  RkKitchens.ini  img/
```

Активный бренд хранится в настройке `BrandActive` (rollhouse | rollclub).
При переключении движок перечитывает данные из `brands/<бренд>/`.

## Что ОБЩЕЕ (engine, пишется один раз)

- Парсинг «грязного» текста (магічне очищення): время, сдача, адрес, мусор.
- Окно-пульт (UI), горячая клавиша `~`, Esc, скрытие по клику вне.
- Внесение в iiko кликами по прицелам (поля, время).
- Оплата (готівка/картка) выбором через печать слова-фильтра.
- Подарки по PLU, калькулятор времени, СИВ (палочки/соусы).
- Короткие таймауты, неблокирующий watchdog, видимые клики с подсказками.
