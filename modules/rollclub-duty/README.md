# Дежурство заказов для RollClub

Дополнение включает ручной режим дежурства по свободным заказам.

- `F4` — включить дежурство;
- повторный `F4` — сразу остановить;
- после открытия первого свободного заказа дежурство останавливается само.

Дополнение не запускает дежурство само и не работает без установленного RollClub.
