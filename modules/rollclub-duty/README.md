# Дежурство заказов для RollClub

Дополнение включает ручной режим дежурства по свободным заказам.

- `Ctrl+F4` — включить дежурство;
- повторный `Ctrl+F4` — сразу остановить;
- после открытия первого свободного заказа дежурство останавливается само.

Дополнение не запускает дежурство само и не работает без установленного RollClub.

Обработчик Ctrl+F4 работает внутри основного процесса RollClub. Дополнение только
разрешает эту функцию, поэтому при установке, отключении или обновлении не
появляется второй процесс AHK и не требуется ручной Reload.

## Свёрнутый Syrve: тестовый путь RollClub 0.1.70

В 0.1.70 исправлен выбор пути: Ctrl+F4 всегда работает через UIA, в том числе
если режим включён до сворачивания окна. Опрос больше не переключает вкладки.
Записи `route` и `scan` в `rollclub_duty_background.log` показывают фактический
путь, состояние окна и номер найденного заказа.

Откройте вкладку «Доставки» в единственном окне Syrve Office, сверните Syrve
и включите дежурство Ctrl+F4. Лаунчер после запуска RollClub можно закрыть.
Для свёрнутого окна используется отдельный UIA-путь без экранных координат,
системной мыши, глобальных клавиш и принудительного разворачивания.

После одного подтверждённого бронирования режим останавливается. Звуковой
сигнал и плашка «Продолжить поиск» появляются после закрытия карточки и
проверки заполненного оператора у нужного номера в таблице. Плашка не
активируется поверх вашей текущей программы. Повторный Ctrl+F4 останавливает
ожидание, в том числе во время HTTP-чтения списка.

Если версия Syrve не предоставляет нужные UIA-pattern для открытия
строки, режим сообщает причину и останавливается. Он не переходит к экранным
кликам. Диагностика: `rollclub_duty_background.log` рядом с основным AHK-файлом.
Ctrl+F4 не переходит к прежнему сценарию и при развёрнутом окне.

Автоматические проверки не заменяют проверку реального Syrve: новый путь ещё
требует операторской проверки на разных версиях Syrve и масштабах Windows.
