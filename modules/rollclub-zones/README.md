# Зони доставки RollClub

Дополнение обслуживает карту зон и таблицу кухонь RollClub.

- хранит пользовательские файлы в `%LOCALAPPDATA%\Programs\RollHelper\UserData\rollclub`;
- позволяет загрузить новый `zones.kml`;
- даёт быстрый доступ к папке зон;
- синхронизирует `RkKitchens.ini` из Google Sheet через штатный скрипт RollClub;
- не включается в базовый MVP RollClub и обновляется отдельно.

После установки дополнения перезапустите RollClub, чтобы базовый пульт увидел модуль.
