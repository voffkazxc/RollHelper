# Отчёт — нагрузка

Дополнение RollHouse читает открытую сгруппированную таблицу «Доставки» напрямую через UI Automation. Названия и количество берутся из групп, суммы — из UIA footer-элементов `Сумма к оплате`.

- Не требует Excel.
- Не использует Telegram.
- Не требует логин или пароль iiko API.
- Не использует сохранённые координаты мыши.
- Показывает короткий отчёт в фиксированном формате: общий итог, затем Берестин, Мерефа и Чугуїв.
- Кнопка `Звіт за день` составляет отдельные живые блоки по каждой точке, учитывает количество заказов и рассчитывает округлённый средний чек.
- Любой из двух вариантов копируется одной кнопкой.

Перед обновлением отчёта оператор должен открыть вкладку «Доставки» в Syrve Office.
